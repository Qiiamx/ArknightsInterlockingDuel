▍抽取规则（当前难度：{{ curDiff().name }} · {{ curDiff().tag }}）
  • 先选满 3 个职业位，点「开始招募」，从开局候选里选 1 名作为起始干员。
  • 3 个职业位可以重复选同一职业（例如医疗×3），此时开局候选都来自该职业。
  • {{ p[0] }}：{{ p[1] }}
  • 之后点下方招募券继续招募，点击干员头像即完成招募（每次选 1 名）。
  • 按 Esc 从当前候选里随机强制选 1 名（招募券会优先随到五星）。
  • 阿米娅的三个形态视为同一名干员：抽到任一形态后，其余形态不再出现。
  • 开局前（主界面）可用 🎲 随机抽取分队，从未被禁用的分队里随机抽一个（可重复抽）；抽到的分队在开局与对局中都会显示。
  • 抽取弹窗内可直接 ＋ 临时干员：手动输入或首字联想加入，不消耗本次抽取。
  • 抽取弹窗内可 ↩ 反悔：招募券的抽取「不选取退出」，该次数会被记录并显示在页面上。
  • 开局弹窗的 ↩ 反悔 · 改选职业 是另一回事：选错职业时作废开局候选、返回职业选择 （已选职业保留可微调），需要二次确认且不计入反悔次数。
  • 张数随难度变化；池子不够时弹窗顶部会提示实际张数。
▍难度说明（在点「开始招募」时选择，本局内不再变更）
  • {{ row.name }}（{{ row.tag }}）：{{ row.summary }}
  • 难度只改变每张券提供多少候选，不改变职业、地形与稀有度规则。
  • 「自刻其痕」可自定义六星 1-5、五星 0-8；五星填 0 表示只出六星，此时必然只能选到六星。

▍全局禁用设置
  • 点右上角「⚙ 全局设置」，可按职业分组检索并多选禁用六星干员，再次点击即解除。
  • 被禁用的干员不会出现在任何抽取中（含开局招募与全部招募券）。
  • 同一界面下方可禁用分队：被禁用的分队不会被「随机抽取分队」抽到。
  • 设置跨局保留——「新的一局」不会清空；刷新页面后仍然生效。
